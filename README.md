# SlideQueue

Presentation playlist and switcher for live shows. Queue PowerPoint, PDF, and Google Slides: one live at a time, on the output you choose.

Free forever, no account required. Part of the [OnQue](https://onque.io) free tools.

## Download

Current version: **1.6.0**

- **Windows:** [slidequeue-setup-win-1.6.0.exe](https://github.com/OnQue-Tools/SlideQueue/releases/download/v1.6.0/slidequeue-setup-win-1.6.0.exe)

All versions are on the [Releases page](https://github.com/OnQue-Tools/SlideQueue/releases).

## What it does

- Ordered queue: arm any item to go live instantly
- Drives PowerPoint, PDF and Google Slides on the monitor you choose, with global hotkeys
- Touch web remote with live slide numbers, from any phone or browser on your network
- Control several SlideQueue machines from one remote, one at a time or all at once
